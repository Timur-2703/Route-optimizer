# Route Optimizer

Инструмент для решения задачи коммивояжёра (TSP) с визуализацией на интерактивной карте.

## Что делает

- Находит оптимальный маршрут между городами
- Сравнивает два алгоритма — жадный и генетический
- Визуализирует маршруты на реальной карте
- Показывает график сходимости генетического алгоритма

## Алгоритмы

**Жадный алгоритм** — на каждом шаге выбирает ближайший непосещённый город. Быстрый но не оптимальный.

**Генетический алгоритм** — использует принципы эволюции: отбор, скрещивание (OX crossover), мутация. Находит более короткие маршруты.

## Стек

- Python 3.12
- matplotlib — визуализация графиков
- folium — интерактивные карты
- geopy — геокодинг городов

## Установка
```bash
pip install matplotlib folium geopy
```

## Запуск
```bash
python main.py
```

## Результаты

Генетический алгоритм стабильно находит маршруты на 10-20% короче жадного.
